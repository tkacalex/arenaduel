# Roadmap

## Foundation

Audit the workspace and required tools. Establish source control, Git LFS, documentation, a fixed engine baseline, and a reproducible C++ project creation workflow. Complete only after the engine and compiler toolchain are installed, Unreal creates the project, and the initial editor target builds.

## Later milestones

1. Establish the smallest replicated character and movement slice.
2. Introduce the Gameplay Ability System and attributes deliberately.
3. Add server authoritative combat mechanics in small verified slices.
4. Add match flow, competitive UI, sessions, dedicated servers, and hosting only in their own planned milestones.

No later milestone is part of the current foundation task.
